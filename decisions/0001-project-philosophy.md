# ADR-0001: Project Philosophy

## Status

Accepted

## Decision

Tring is a developer-first toolkit focused on JSON translations.

The project values:

- Simplicity over complexity.
- Convention over configuration.
- Modern Node.js.
- TypeScript-first.
- Excellent developer experience.

## Consequences

- Avoid unnecessary abstractions.
- Add features only when solving real problems.
- Keep the public API as small as possible.
